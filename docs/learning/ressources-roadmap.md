# Ressources d'Apprentissage - Software Engineering (Roadmap 90 Jours)

### 1. Architecture et Design Modulaire
*   **[Clean Architecture](https://www.oreilly.com/library/view/clean-architecture-a/9780134494272/)** (Robert C. Martin) : Séparation des responsabilités.
*   **[Refactoring: Improving the Design of Existing Code](https://martinfowler.com/books/refactoring.html)** (Martin Fowler) : Nettoyage de dette technique.
*   **[The Twelve-Factor App](https://12factor.net/)** : Conception d'applications robustes.

### 2. Tests et Qualité
*   **[Working Effectively with Legacy Code](https://www.oreilly.com/library/view/working-effectively-with/0131177052/)** (Michael Feathers) : Tester et refactorer du code existant.
*   **[Test-Driven Development: By Example](https://www.oreilly.com/library/view/test-driven-development-by/0321146530/)** (Kent Beck) : Approche *test-first*.
*   **[Testing Pyramid](https://martinfowler.com/articles/practical-test-pyramid.html)** (Martin Fowler) : Équilibre des tests (unitaires/intégration/E2E).

### 3. Git et Livraison
*   **[How to Write a Git Commit Message](https://cbea.ms/git-commit/)** (Chris Beams) : Commits atomiques.
*   **[Conventional Commits](https://www.conventionalcommits.org/)** : Standardisation des messages de commit.
*   **[Anatomy of a Perfect Pull Request](https://hugooodias.medium.com/the-anatomy-of-a-perfect-pull-request-567382bb6067)** : Bonnes pratiques de revue de code.

### 4. Debugging
*   **[Debugging: The 9 Indispensable Rules](https://www.oreilly.com/library/view/debugging-the-9/9780596516642/)** (David J. Agans).
*   **[Rubber Duck Debugging](https://en.wikipedia.org/wiki/Rubber_duck_debugging)** : Méthodologie d'isolement par explication.

### 5. Fiabilité et Résilience
*   **[Release It!](https://pragprog.com/titles/mnee2/release-it-second-edition/)** (Michael T. Nygard) : Timeouts, retries, circuit breakers.
*   **[Idempotence](https://restfulapi.net/idempotent-methods/)** : Conception de flux rejouables.

### Outils et Pratique
*   **[Exercism](https://exercism.org/) / [Kata Log](https://sammancoaching.org/coding_dojo/coding_dojo.html)** : Pratique TDD et refactoring.
*   **Automatisation** : Scripts (npm/make/bash) + pre-commit hooks (Husky).
